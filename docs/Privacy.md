# Take: privacy

Take keeps your manuscript on your Mac, as files in a folder you choose,
with its history in a git repository inside that folder. Take has no
account, no server and no analytics. It collects nothing about you and
sends nothing anywhere on its own.

Three things can leave your Mac, each only when you ask:

- **Three Takes** sends the open scene, the scenes on either side of it,
  and the scene's beat sheet if there is one, to Anthropic's API under an
  API key you enter yourself. Anthropic's handling of that text is governed
  by Anthropic's own terms and privacy policy. Take asks before each send
  unless you turn that off in Settings. The key is stored in the macOS
  keychain and never shown again.
- **Back Up** pushes the project's git repository to a remote you name,
  over HTTPS, with an access token you enter yourself. The token is stored
  in the keychain.
- **Export** writes a Markdown, Word or PDF file where you choose.

Untangle runs on Apple's on-device model and sends nothing.

Take does not use cookies, advertising identifiers, or any third-party
SDK. The only network connections it makes are the two above.
